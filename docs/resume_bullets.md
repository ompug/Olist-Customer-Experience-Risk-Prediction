# Resume Bullet Options

- Built a leakage-aware ML pipeline on 95K+ e-commerce orders, aggregating relational order, payment, product, seller, customer, and review data into a reusable Python package.
- Engineered time-aware seller, category, and customer-state historical risk features using only prior orders, improving future-order ROC-AUC from 0.5999 to 0.6146.
- Developed an intervention simulation showing the top 10% riskiest future orders captured 451 low-review cases with 2.43x lift over random selection.
- Refactored a notebook-only ML project into a tested Python codebase with reproducible scripts, pytest coverage, and a Streamlit results dashboard.
- Presented model validation, threshold tradeoffs, and intervention planning through a lightweight dashboard backed by saved evaluation artifacts.
